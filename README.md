# Cinema Ticket Booking System
The Cinema Ticket Booking System is a Java-based application developed using Object-Oriented Programming (OOP) concepts. It is designed to streamline and manage the process of booking movie tickets efficiently for different types of users. Specific functions are assigned to each role to ensure smooth operation and management of the cinema services.

# Roles
1. Ticketing Clerk
2. Cinema Manager
3. Customer

# Features
1. Ticketing Clerk
- Clerk login authentication
- Book cinema tickets
- Cancel or modify bookings
- Search for bookings
- View screen details
- Process payments and generate receipts
- View receipts

2. Cinema Manager
- Manager login authentication
- Add new movies
- Manage showtimes
- Manage cinema halls
- Set ticket prices
- View reports

3. Customer
- Customer registration
- Customer login authentication
- View and edit profile
- View movie list
- View booking history

# Technologies Used
- Java
- Java Swing (GUI)
- Object-Oriented Programming (OOP)
- Text File Handling

# Development Tool
- Apache NetBeans

# How to Run
1. Download this repository.
2. Open the project in Apache NetBeans.
3. Run the CinemaBookingSystem.java to start the application.
